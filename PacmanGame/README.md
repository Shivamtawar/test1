# Pac-Man Maze

A small, single-level Pac-Man-style browser game built with vanilla HTML, CSS, JavaScript, and Canvas 2D. It has no dependencies or build step.

## Run

Open `index.html` in a modern desktop browser.

## Controls

- Use the arrow keys to move through the maze.
- Collect all dots (10 points each) and power pellets (50 points each).
- All four ghosts begin inside the central pen. Red, Pink, Blue, then Orange are released at 100, 200, 300, and 400 points.
- Avoid released ghosts. Each collision costs one life; the game starts with three.
- Select **Restart Game** after winning or losing to start a fresh run.

Power pellets are collectibles only in this version and do not change ghost behavior.
